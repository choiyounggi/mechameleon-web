# stickmeleon

메차카멜레온에서 영감을 받은, 업무 중 몰래 즐기는 웹 숨바꼭질 게임.

- 1명(랜덤 선정)이 숨고, 나머지가 찾는다 (최소 2인).
- 숨는 사람: 원하는 웹 주소를 입력하면 서버가 해당 페이지의 스크린샷(겉보기만 동일, 동작 안 함)을 배경으로 제공. 방향키로 졸라맨을 움직여 위치를 잡고, 스포이드로 배경색을 따서 부위별로 색칠해 위장.
- 찾는 사람: 각자 자유 스크롤로 탐색, 클릭으로 지목. 빗나가면 본인만 3초 클릭 잠금 + 전원 화면에 은은한 파문 표시. 제한 시간 내 못 찾으면 숨은 사람 승리.
- 실시간 동기화: WebSocket(Socket.io). 방 코드로 입장, 단판 승부.

## 스택

- 서버: Node.js + TypeScript, Express, Socket.io, Playwright(스크린샷)
- 클라이언트: Vite + TypeScript, Canvas
- 상태: 메모리 전용 (DB 없음)
